# 光伏项目助理工作助手 · Solar Workbench

分布式光伏（屋顶/工商业）项目助理的一站式工作台：**待办不漏、项目不乱、提成不错**。

## 功能
- 首页仪表盘：今日待办、今日计划、项目概览、提成、提醒中心
- 待办：到期自动常驻、逾期标红、老板交办高亮、P0→P1→P2 排序
- 随手记：3 秒速记 + AI 解析（项目/截止/容量/动作/负责人/优先级）→ 一键转待办
- 项目看板：按阶段拖拽（开发→备案→建设→并网→运维）
- 通讯录、现场速记（含勘察模板）、文档库（到期提醒）、提成追踪（密码锁）
- 日报/周报一键生成、数据导出导入、PWA 离线可用

## 技术
纯静态前端（原生 JS + localStorage），无需后端。可直接用任意静态托管（GitHub Pages / 任意 Web 服务器）部署。

## 使用
用浏览器打开部署地址即可。数据保存在浏览器本地（localStorage）；换设备请用「我的 → 数据导出/导入」迁移。
